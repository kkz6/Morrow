# Website assets

- `public/images/morrow-icon.png`: Morrow application icon, exported from `Resources/AppIcon.icns`.
- `public/images/morrow-workspace.png`: native Morrow settings screen, rendered with example projects through the application's snapshot mode; it contains no user project data.
- `public/images/workspace-pattern.png`: original generated illustration for Morrow, using linked rounded paths and nodes. It is not an asset from the design reference.
- Inter Variable and Fraunces Variable: self-hosted through Fontsource packages, licensed under the SIL Open Font License. Package license files remain in the source dependencies.
- Phosphor icons: `@phosphor-icons/vue`, MIT licensed. Icons are bundled as components; the website does not fetch icons at runtime.

Shared palette, typography, spacing, and controls live in `app/assets/main.css`. The same website foundations can be adapted for related products without copying their product content or imagery.
